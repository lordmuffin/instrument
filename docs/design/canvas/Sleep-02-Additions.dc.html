Sleep Dashboard · 2 · What Sleep adds

Six additions for Instrument v0.2

Sleep needs five new parts and one written-down pattern. Each is named for what it does, not for sleep, so the next app can use it. They use existing tokens only, and live in instrument-proposed.css until the system takes them.

⚑ ProposedNot in instrument.css yet. Each needs its sheet entry and both themes before it merges.
1 · New variant.i-chip--amended · --off

Review chip

To review Corrected, not confirmed ⚑ Watch data changed ✓ Confirmed ✓ Corrected Review unavailable

Need. A record a person checks has six verdicts. Three need action, and the chip has to say which.

Closest today: status chip. It says how a job went. It has no way to show "checked, with your changes", and its disabled grey is too faint for text.

surface-2 · text-2 · warning · success · line

2 · New component.i-facts · .i-fact · .i-was

Fact grid

Into bed
23:05 watch: 23:40Sun 11 Oct · CDT
Efficiency
91.4%sleep ÷ in bed

Need. A record is a handful of named readings. Some were corrected by hand, and the original must stay visible.

Closest today: a block with a stat inside it. It has no label and value markup, and nowhere to keep the value before a correction.

surface · label · stat · meta mono · warning

3 · New component.i-choiceform

Inline choice form

Need. Confirm many nights from a list without opening each one.

Closest today: dense table row states, which already cover saving, saved and failed. This writes down the wording, and that the chip changes in the same swap.

accent-tint 2 s · error-tint · spinner

5 · New chart type.i-radial

Radial clock

Need. Times that wrap midnight. On a straight axis, 23:50 and 00:10 land a day apart.

Closest today: trend line. It breaks at midnight, so a late Friday looks like a gap.

chart-1 · chart-2 · chart-4 · mean line · grid · baseline

Need. Keep room for a feature that is coming, so the page does not jump when it ships.

Closest today: empty state. It means "no data yet", which would be wrong here.
